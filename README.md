# irshape

irshape quantifies intron retention (IR) directly from precomputed RNA-seq
coverage — bigWig coverage plus a junction-count table, or a BAM file — with
no alignment step of its own, so it scales to cohort-sized inputs (e.g.
recount3/GTEx-scale bigWigs). It implements the IRFinder *principle* (median
coverage over masked intronic positions vs. flanking splice-junction depth)
with two corrections on top: a mask policy that stops over-masking same-gene
alternative-isoform exons, and a per-length-tier coverage-shape layer that
turns raw coverage into a calibrated retention-confidence signal instead of a
bare ratio. Output is one schema-conformant, versioned TSV per run — see
`SCHEMA.md` for the full column contract.

## Installation

```
pip install -e .
```

Requires Python >=3.9. Dependencies (numpy, pandas, pysam, pyBigWig) install
automatically; the engine itself was developed and validated against
numpy 2.2.6, pandas 2.3.3, pysam 0.22.1, pyBigWig 0.3.25.

Container builds are also provided (`Dockerfile`, `Apptainer.def`) — neither
bakes in reference data (see "Get the reference" below):

```
docker build -t irshape .
apptainer build irshape.sif Apptainer.def
```

## Get the reference

irshape needs a GTF, a genome FASTA, a mappability track, and a PolyASite
atlas (plus prebuilt per-length-tier mask/GC/mappability caches, an
expensive one-time genome-wide sweep) to build its intron reference. These
ship as a separate, versioned download rather than inside the package:
**`irshape-ref-GRCh38-gencodeV44`** — Zenodo DOI `10.5281/zenodo.PLACEHOLDER`
(fill in after the reference bundle is deposited).

Extract it, then point irshape at it with `--ref-dir` or `$IRSHAPE_REF`:

```
export IRSHAPE_REF=/path/to/irshape-ref-GRCh38-gencodeV44
# or: irshape run --ref-dir /path/to/irshape-ref-GRCh38-gencodeV44 ...
```

Individual `--gtf`/`--fasta`/`--mappability-bigwig`/`--polya-bed` flags work
standalone (no `--ref-dir` needed) and override whatever a given `--ref-dir`
supplies. `build_reference_bundle.py` documents how the bundle itself is
assembled from those underlying artifacts (see "Rebuilding the reference
bundle" below) — most users just download the published bundle instead.

## Input adapters

Two adapters share one interface (`irshape/adapters/base.py`):

- **`recount3`** (`--input recount3`) — precomputed bigWig coverage plus a
  pre-parsed junction table (columns `intron_id, splice_left, splice_right,
  splice_exact`, one row per intron). This is the scale path: no BAM
  download or alignment, works directly against recount3-style per-study
  coverage and junction flat files.
- **`bam`** (`--input bam`) — pysam over a local BAM file, for cohorts
  without recount3 coverage. **Stubbed** in this release (interface only;
  raises `NotImplementedError`) — a future release will implement it.

## Minimal worked example

`quickstart/` contains a complete, tiny example: VIM (vimentin), whose 9
introns happen to span all three of the engine's length tiers
(`sub_read`/`awkward_mid`/`long`) in one gene. `quickstart/vim_junctions.tsv`
is the junction-count input (9 rows, ready to use); `quickstart/vim_out.tsv`
is the expected output, generated by the same command below, for comparison.

```
irshape run \
    --ref-dir irshape-ref-GRCh38-gencodeV44 \
    --input recount3 --genes VIM \
    --bigwigs sample1.bw,sample2.bw,sample3.bw,sample4.bw \
    --junctions quickstart/vim_junctions.tsv \
    --out vim_out.tsv
```

Substitute any bigWigs covering chr10:17,228,525-17,237,229 (GRCh38) for
`sample*.bw` — e.g. a recount3 GTEx or SRA study bigWig for a whole blood or
fibroblast sample, fetched from recount3's public data (no controlled
access needed). This runs the **full** tiered engine by default (Block 1
classic + Block 2 full-shape + Block 3 two-point, merged into one
schema-conformant table). Pass `--classic-only` for the lighter Block-1-only
path (single unscoped bundle, no shape/GC/IPA/annotation columns).

## Output schema

One row per `(intron_id, mask_policy)`, `mask_policy` in `{classic,
best_perf}`. Full formulas, units, and validation numbers are in
**`SCHEMA.md`**; below is a one-line-per-column summary.

| column | description |
|---|---|
| `intron_id` | `GENE:i<idx>:<start>-<end>` identifier |
| `chrom`, `start`, `end`, `strand` | genomic coordinates (1-based inclusive) |
| `gene_id`, `host_biotype` | Ensembl gene ID and GENCODE gene_type of the intron's own gene |
| `length`, `length_tier` | intron length in bp and its routing tier (`sub_read` <100bp, `awkward_mid` 100-999bp, `long` >=1000bp) |
| `intron_abundance_Ai` | median per-base coverage over unmasked intronic positions |
| `splice_left`, `splice_right`, `splice_exact` | junction depth at the donor site, acceptor site, and the exact intron-excision junction |
| `coverage_fraction` | fraction of unmasked intronic bases with coverage > 0 |
| `IRratio_classic` | `Ai / (Ai + Ae)`, the classic IRFinder-style ratio |
| `warn_LowCover`, `warn_LowSplicing`, `warn_MinorIsoform`, `warn_NonUniformCover` | data-quality flags (see SCHEMA.md for exact thresholds) |
| `tag` | `clean` / `other-overlap` / `anti-near`, describing overlap with other-gene exons |
| `mask_policy` | `classic` or `best_perf` — which masking rule produced this row |
| `masked_fraction`, `mask_other_gene_frac`, `mask_same_gene_frac` | fraction of the intron excluded from measurement, and by which overlap type |
| `uniformity` | Shannon-entropy evenness of binned coverage over the unmasked intron (long tier) |
| `gradient_score` | unvalidated — coverage slope vs. position; do not use for inference |
| `cliff_score`, `cliff_position` | largest single-step coverage drop between adjacent bins, and where it occurs |
| `two_point_ratio` | donor-window vs. acceptor-window coverage share (awkward_mid tier) |
| `shape_method` | which shape fitter was used: `full_shape`, `two_point`, or `junction_only` |
| `shape_fittable` | whether the chosen shape method had enough valid data for this intron |
| `gc_content`, `mappability_score` | mean GC fraction / mean k100 mappability over unmasked bases |
| `gc_transition_near_shape_feature`, `shape_bias_flag` | technical-confound flags near a detected shape feature |
| `ipa_cliff_score`, `ipa_position` | ranking-only internal-poly(A)/alt-3'-end candidate signal (not a calibrated call) |
| `ipa_annotation_support` | whether a PolyASite/GENCODE alt-3' site corroborates `ipa_position` |
| `ipa_candidate` | hypothesis-generating IPA candidate flag (~9% precision at ~32% recall; shortlist only, never assert) |
| `ipa_flag`, `ipa_confidence` | retired; always null, kept for schema compatibility |
| `IRratio_corrected` | production retention estimate: `IRratio_classic` under the `best_perf` mask |
| `IRratio_shrunk` | reserved for a future empirical-Bayes shrinkage correction (currently null) |
| `retention_confidence` | per-tier-calibrated confidence in the retention call (not comparable in magnitude across tiers) |
| `minor_intron_U12` | approximate motif-similarity flag for U12-type (minor spliceosome) introns |
| `polyA_site_present`, `alt3ss_present` | whether a PolyASite/alt-3' annotation falls anywhere inside the intron |
| `tier`, `method`, `confidence` | provenance fields: measurement regime, which computation produced the row, and a coarse Block-1 confidence placeholder |

## Mask policies

Both policies mask *other-gene* exon overlap. They differ only in whether a
base covered by both an other-gene exon and a same-gene (alternative-isoform)
exon gets masked; an alternative-isoform exon of the intron's *own* gene
never erases intronic signal by itself under either policy.

| policy | masks other-gene overlap | masks same-gene-only overlap | default |
|---|---|---|---|
| `classic` (traditional IRFinder masking) | yes | yes | audit baseline only |
| `best_perf` (corrected) | yes | no | **yes** |

`best_perf` is the default because unmasking same-gene-only overlap recovers
real retention signal that `classic` destroys: in this project's validation,
it recovered 49-53 of 311 (~16-17%) previously-unmeasurable RETENTION
introns, with zero false-inflation against long-read ground truth on the
checkable cases. `classic` — masking any exonic overlap regardless of gene
of origin, the literal traditional IRFinder rule — is kept only so callers
can audit against it; it is known to destroy real signal (e.g. a validated
CLK1 intron-4 case) and should not be used as a default.

## Rebuilding the reference bundle

`build_reference_bundle.py` assembles an already-built GTF, genome FASTA,
mappability bigWig, PolyASite bed, and per-tier reference caches into one
versioned, checksummed bundle in the layout `--ref-dir` expects. It collects;
it does not build the per-tier caches itself (run `irshape build-reference`
first for a new genome/annotation). Paths default to two environment
variables instead of being hardcoded:

```
export IRSHAPE_BUILD_ROOT=/path/to/your/project       # holds results/, data/external/
export IRSHAPE_BUILD_ANNOT_DIR=/path/to/annotations   # holds the GTF + genome FASTA
python build_reference_bundle.py --out-dir irshape-ref-mygenome
```

Every default can also be overridden directly with its own flag
(`--gtf`, `--fasta`, `--mappability-bigwig`, `--polya-bed`, `--long-cache`,
`--awkward-mid-cache`, `--intron-universe`, `--genome-build`,
`--annotation-version`) — see `python build_reference_bundle.py --help`.

## What's actually validated (read before trusting a number)

- `retention_confidence` is calibrated **per length tier**, not on one shared
  scale — do not compare its values across tiers as if they were on the same
  scale (see `SCHEMA.md`'s Block 2c/3 addenda for the AUC figures behind
  each tier's calibration).
- `IRratio_corrected` currently equals `IRratio_classic` on `best_perf` rows
  by design — the two validated corrections baked in are the `best_perf`
  mask and the median-coverage estimator, nothing else yet.
- `ipa_candidate`/`ipa_cliff_score` are ranking/candidate signals only,
  never a calibrated IPA call (roughly 9 in 10 candidates are not actually
  IPA against long-read truth) — use them to shortlist, not to assert.
- Short-read IRratio vs. long-read PIR reaches Spearman rho ~= 0.44 at best
  (high-confidence, cytosol) — treat short-read IR as the scalable feature
  and long-read PIR as gold standard wherever both exist, not as
  interchangeable measurements of the same quantity.

See `SCHEMA.md` for the full derivation and validation detail behind every
claim above.
